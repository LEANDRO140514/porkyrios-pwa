## Stack

- App: Porkyrios PWA (restaurant ordering: menu, cart, payment, order tracking, admin).
- Framework: Next.js 15 (App Router) + React 19, TypeScript, Tailwind CSS, Radix UI / shadcn components (`src/components/ui`).
- Database: Turso/libsql via Drizzle ORM (`src/db`, migrations in `drizzle/`, config `drizzle.config.ts`).
- Auth: better-auth (email + Google/Facebook OAuth).
- Payments: MercadoPago (primary, `/payment`); Stripe SDK also installed.
- Email: Resend + react-email (`src/emails`).
- Monitoring: Sentry (`@sentry/nextjs`); analytics via GA/GTM.
- Other integrations: GoHighLevel (`/api/ghl`), web push (VAPID), referrals, coupons, reviews.
- Agent layer: SlashStack.

## Commands

- Package manager: bun (`bun install`; `.orchids/orchids.json` uses `bun install; bun dev`). A `package-lock.json` also exists.
- Dev: `npm run dev`
- Test (unit/component, Vitest): `npm run test:run`
- Test (E2E, Playwright, `src/test/e2e`): `npm run test:e2e`
- Lint: `npm run lint` (next lint)
- Build: `npm run build`

## Constraints

- Build needs `TURSO_CONNECTION_URL` at build time (the libsql client is created at module load); without it `next build` fails while collecting page data. `RESEND_API_KEY` is optional: the Resend client in `src/lib/resend.ts` is created lazily and `sendEmail` returns `success: false` when the key is missing.
- `next.config.ts` sets `typescript.ignoreBuildErrors` and `eslint.ignoreDuringBuilds`, so a passing build does not mean types or lint are clean.
- Vitest also picks up the Playwright files in `src/test/e2e/*.spec.ts`, which fail under Vitest ("did not expect test.describe()").
- Env vars reference: `.env.example` (never commit `.env*` files with real values).
